# YAFS5 Depressive Symptoms Analysis

This repository contains the Jupyter notebooks used in the study **YAFS5 Depressive Symptoms Analysis**. The project examines High Depressive Symptoms (HDS) among Filipino youth in the National Capital Region (NCR) using data from the Fifth Young Adult Fertility and Sexuality Study (YAFS5).

The notebooks document the study's data preparation, exploratory data analysis, feature selection, model development, model evaluation and selection, and interpretable machine learning procedures.

> **Data access and privacy:** The YAFS5 respondent-level dataset is restricted and is not included in this repository. Users must obtain the dataset through the appropriate data-access process and comply with the applicable data-use conditions. Do not upload the original dataset, reduced respondent-level files, train/test splits, or other restricted respondent-level data to this public repository.

## Repository contents

| Notebook | Description |
|---|---|
| `NB1_Data_Preprocessing.ipynb` | Loads the YAFS5 SPSS file, selects the study variables, derives the HDS/MNDS outcome, filters the NCR analytical sample, handles nonresponse and selected skip-pattern values, prepares model-specific datasets, and creates stratified training and test splits. |
| `NB2_Exploratory_Data_Analysis.ipynb` | Examines the outcome distribution and variables across thematic groups using descriptive statistics and visualizations. It also includes the statistical and correlation analyses and missing-data assessment implemented in the notebook. |
| `NB3_Feature_Selection.ipynb` | Performs model-specific feature selection for Logistic Regression (LR), Random Forest (RF), and Artificial Neural Network (ANN), using LASSO stability selection for LR and bootstrapped permutation importance for RF and ANN. It prepares fold-specific data and a manifest for subsequent model development. |
| `NB4_Model_Development.ipynb` | Develops baseline and tuned LR, RF, and ANN models using the fold-specific data from NB3. It performs model tuning and saves fitted models and supporting model outputs. |
| `NB5_Model_Evaluation.ipynb` | Evaluates and compares the six baseline and tuned model configurations, calculates evaluation metrics and bootstrap confidence intervals, and selects a model using the training cross-validation ranking procedure. |
| `NB6_Interpretable_Machine_Learning.ipynb` | Interprets the selected model using Individual Conditional Expectation (ICE) analyses, including regular and centered ICE plots, group comparisons, and supplementary summaries of model-prediction patterns. |

## Notebook execution order

Run the notebooks in the following order:

1. **NB1 – Data Preprocessing**
2. **NB2 – Exploratory Data Analysis**
3. **NB3 – Feature Selection**
4. **NB4 – Model Development**
5. **NB5 – Model Evaluation**
6. **NB6 – Interpretable Machine Learning**

NB2 uses the cleaned EDA and national-context outputs produced by NB1. NB3 uses the preprocessed training/test data from NB1. NB4 uses the fold-specific datasets and manifest generated by NB3. NB5 uses the fitted models and training outputs from NB4. NB6 uses the selected-model information from NB5 together with the saved model and data outputs from the earlier notebooks.

Run the notebooks from the project root directory so that their relative paths resolve correctly. Execute the cells in order, and retain the generated intermediate files in the expected output directories between notebook runs.

## Required data and folder setup

The notebooks expect the restricted source data and generated intermediate files to be available locally. They are not provided in this repository.

### Source data

NB1 expects the original YAFS5 SPSS file at:

```text
Raw Dataset/
└── YAFS5 Individual.sav
```

NB1 also creates a reduced-variable CSV in:

```text
Reduced Dataset/
└── YAFS5_reduced_vars.csv
```

This reduced file is generated by NB1; it is not a substitute for the original SPSS source file.

### Generated outputs

The notebooks exchange intermediate files through these output directories:

- `NB_OUTS1/` – stores the outputs generated by NB1 and used by NB2 and NB3, as well as relevant EDA outputs.
- `NB_OUTS1_TRAINONLY/` – stores fold-specific feature-selection, model-development, evaluation, and interpretation outputs used by NB3–NB6.

NB1, NB2, and NB3 are configured to use these matching directory paths. NB1 writes its outputs to `NB_OUTS1/`, NB2 reads the relevant NB1 files from `NB_OUTS1/`, and NB3 reads its input files from `NB_OUTS1/` while writing its outputs to `NB_OUTS1_TRAINONLY/`.

NB6 also expects the model-selection information, selected fitted model, training/test data, and other outputs created by NB3–NB5. Do not run NB6 independently without first running the preceding notebooks or providing their required outputs.

## Environment setup

Use Python with Jupyter Notebook or JupyterLab.

Create and activate a virtual environment, then install the dependencies listed in `requirements.txt`:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

Install the packages:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Start Jupyter:

```bash
jupyter lab
```

Alternatively:

```bash
jupyter notebook
```

## Reproducibility notes

- The notebooks use a fixed random seed of `42` in the relevant preprocessing, feature-selection, and modeling procedures.
- NB3 performs computationally intensive, fold-specific feature selection with bootstrap-based procedures. Runtime depends on the computer and the configured number of resamples.
- Outputs and plots are generated locally when the notebooks are executed.
- A cleared notebook output does not remove the code. Re-run the relevant cells to regenerate tables, figures, and intermediate files.
- Package versions and computational environments can affect reproducibility. For a formal reproduction, record the Python version and installed package versions used for the final analysis.

## Important interpretation note

The HDS/MNDS outcome is a study classification derived from the CES-D score using the cutoff specified in the manuscript. The models and ICE analyses describe classification patterns and model-predicted probabilities; they do not establish causal relationships or provide clinical diagnoses.
